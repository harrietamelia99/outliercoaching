How to manage your Outlier Coaching website

This guide is for you if you want to change words, pictures, testimonials, or event listings yourself. Take your time. You can’t break the whole internet by typing in the wrong box—and you can usually change things back.

1. How to log in

  1. Open your web browser (Safari, Chrome, Edge, or Firefox).
  2. In the address bar at the top, type the same web address you use for your public site, then type /wp-admin straight after it (no space). So your login address is always: your normal site address, plus /wp-admin on the end.
  3. Press Enter.
  4. Enter the username and password you were given. If you don’t have them, ask the person who built the site.
  5. After you log in, you’ll land on the Dashboard. That’s the control room: a menu runs down the left side, and the middle shows summaries and shortcuts. Don’t worry about every item in the menu—you only need a few of them.

2. How to edit text on the main page

Most of your homepage is not built from the small content blocks in the middle of the screen. It is controlled by a special panel called Outlier Landing Fields, which sits below the main editor when you open the right page.

  1. In the left menu, click Pages.
  2. Find the page that is set up as your main landing page (often named “Home” or similar). Click its title to open it.
  3. Check that this page uses the Outlier Landing template. You’ll find that under Page settings on the right (in the sidebar), in a section called Template. If it doesn’t say Outlier Landing, stop and ask for help—editing the wrong template won’t change the public homepage.
  4. Scroll down past the big main editor area. You’ll see a box titled Outlier Landing Fields, split into sections like “Hero”, “Testimonials”, and so on.
  5. Click in any text field you want to change. Type your new words.
  6. When you’re finished, click the blue Update button (top right). Wait until you see a short confirmation that the page saved.
  7. Open your live website in another tab to check how it looks. It can take a moment to refresh; try a normal refresh first, or hold Shift while refreshing if the old text still shows.
About the big editor above: Your site can use WordPress’s block editor for extra notes or other pages. For the main Outlier homepage, treat Outlier Landing Fields as the place where headline text, button labels, testimonials, and events live.

3. How to swap an image

Images for the hero background, logos, and the “What this is” cards are chosen inside Outlier Landing Fields, not by clicking pictures on the live site.

  1. Open the correct page (see section 2) and scroll to Outlier Landing Fields.
  2. Find the image you want to change (for example Hero background image or Image under one of the cards).
  3. Click Select image. WordPress will open your Media Library (your collection of uploaded files).
  4. To use a picture already in the library, click it once, then confirm. To upload a new file from your computer, use the Upload files tab, choose your file, wait for it to finish, then select it.
  5. If you need to remove a custom image and go back to the site’s built-in picture, use the Remove button next to that image field (if shown).
  6. Click Update on the page to save.

Keeping things looking good:

  • Use JPG for photos, PNG if you need a transparent logo.
  • For the wide hero background, a large, wide photo works best (think landscape, not a tall phone snapshot).
  • For card images, wide photos generally match the wide rectangles on the page. Avoid tiny images that might look blurry when stretched.
  • Before uploading, try to keep each file to a sensible size (for example under a few megabytes) so the site stays fast.

4. How to add or change a testimonial

Testimonials are not a separate list elsewhere in WordPress. They are text boxes on your landing page, managed in Outlier Landing Fields.

  1. Open your landing page (see section 2).
  2. Scroll in Outlier Landing Fields to the Testimonials section.
  3. You’ll see a section label (for example “What people say”) and numbered boxes: Testimonial 1, Testimonial 2, and so on, up to Testimonial 12.
  4. Each box holds the quote only. There isn’t a separate field for the person’s name or job title on this design—if you want that, include it inside the quote text in your own words.
  5. To add another testimonial, find the next empty numbered box and paste or type the quote there. Order matters: number 1 appears first, then 2, then 3, and so on.
  6. To hide a testimonial, delete all the text in that box and save. Empty boxes don’t show on the website.
  7. Click Update to save. There is no separate “Publish” button for each quote—the page update is what makes changes live.

5. How to add or change an event

Events (shown in the “Upcoming adventures” style section) are also on the same landing page, under Outlier Landing Fields. There is no separate “Events” area in the left menu for this design, and no photo field per event in this theme—only text and a link.

  1. Open your landing page and scroll to Upcoming events (adventures) inside Outlier Landing Fields.
  2. You’ll see Event 1, Event 2, … up to Event 12. Each event has:
    • Title — the name of the event (required for it to show).
    • Date / venue (one line) — for example dates or place names.
    • Short description (optional) — extra detail if you want it.
    • Find out more — link URL — optional. Leave blank if the button should simply scroll visitors to your contact section. Or paste a full web address (for example a PDF in the Media Library, a YouTube link, or another page).
  3. To add a new event, fill in the next numbered event that is still empty.
  4. To remove an event from the site, clear its Title and save. If the title is empty, that card stays hidden.
  5. Click Update to save your changes.

6. How to replace a file (for example a PDF flyer)

  1. In the left menu, click Media, then Library.
  2. Find your PDF. You can use the search box if you remember part of the file name.
  3. To add a new file, click Add New, upload the PDF, and wait until it finishes.
  4. Click the file in the library to open its details. Copy the File URL (sometimes labelled “Copy URL to clipboard” or shown as a link). You’ll paste that address into an event’s “Find out more” field or wherever the download should point.
Important: If you upload a replacement PDF as a brand-new file, it gets a new web address. Any old button that still used the old address will keep pointing to the old file until you edit that button’s link and paste the new URL. If you are not sure where a link was set, check the event’s “Find out more” field and any similar fields on your landing page.

7. Things to avoid

  • Don’t edit theme files, code, or hosting settings unless you know what you’re doing—or ask whoever supports the site.
  • Don’t delete the main landing page itself.
  • Don’t change the page template away from Outlier Landing unless someone technical asks you to.
  • Be cautious with Plugins and big WordPress updates. Updating can be fine, but If something offers to update many things at once and you’re unsure, ask first.
  • Don’t worry: changing text in the right boxes and clicking Update is a normal, safe thing to do. You can usually put the old wording back by typing it again.

Need more than this? Small text and image changes are what this guide is for. If you want new page layouts, new types of content, online shop features, or anything that feels like “rebuilding” part of the site, speak to your developer for a separate piece of work and quote.
